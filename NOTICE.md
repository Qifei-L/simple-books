# Upstream projects

The web application adapts Refine's official `examples/auth-antd` template:
https://github.com/refinedev/refine/tree/main/examples/auth-antd

Retains its Refine / Ant Design layout, AuthPage, routing, notifications and
bootstrap/config structure. Replaces mock authentication, fake posts API and
example pages with the Simple Books API and accounting pages.
